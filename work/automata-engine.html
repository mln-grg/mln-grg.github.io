automata-engine

Conway's Game of Life in C++20 and SDL2, on a 1920 by 1080 grid. A learning project: I wanted to get better at modern C++ and find out for myself how much speed is actually on the table in a hot loop.

Language
C++20, SDL2
Grid
2,073,600 cells
Version
1 of a planned 4
Source
github.com/mln-grg/automata-engine
  • Two million cells simulated and drawn every frame, with the simulation and draw cost printed live on screen so the effect of any change is immediately visible.
  • On an i7-12700F, release build: SIM 14.3 ms, DRAW 1.6 ms, 145 MCELLS/S, FPS 51.8.
  • I am writing it four times. Same rules and same output every time, only the inner loop changes, measured on the same machine, flags, seed and grid size so the numbers actually compare.
  • The four passes: the obvious version, then cache friendly flat arrays with nothing allocated in the loop, then bit packing 32 cells into a uint32 and computing all 32 at once, then parallelism, threading the grid and finally pushing it onto the GPU.
  • The grid is a flat vector indexed y*W+x and the simulation never touches rendering, so each rewrite is a swap rather than a rebuild.
  • Patterns load from patterns/ as RLE files, the format Golly and the LifeWiki use. 22 in the folder, nothing hard coded.
