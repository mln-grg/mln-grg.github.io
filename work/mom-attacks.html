Mom Attacks

A 2D platformer with boss encounters, built in Unity. Small on purpose: boss fights are the cheapest way to practise state-driven combat, telegraphing and encounter pacing, because everything that makes a fight readable has to be explicit.

Type
Personal project
Engine
Unity, C#
Focus
Boss state machines, feel
Source
On GitHub

What it was for

A boss fight is a state machine that the player has to be able to read without being told the rules. Every attack needs a telegraph long enough to react to and short enough to feel fair; every phase transition needs to be legible; and the whole thing has to stay interesting on the twentieth attempt, when the player already knows the pattern.

That makes it good practice for exactly the thing gameplay programming is judged on — feel. Not whether the mechanic works, but whether the timing windows, animation cancels and recovery frames add up to something that reads as fair when the player loses.

What carried forward

The state-machine discipline. Boss behaviour written as explicit states with explicit entry, exit and transition conditions stays debuggable when it grows; boss behaviour written as flags and coroutines does not. That is the same pattern I later used for soldier presentation states in a battle with four thousand of them — the scale changed, the argument for explicit states did not.
