Combat GAS Project

A combat framework built on Unreal's Gameplay Ability System, structured after Lyra. In progress, and this page says what is and is not built.

Type
Personal project
Engine
Unreal Engine 5, C++
Status
In progress, started Aug 2026
Source
github.com/mln-grg/Knight
  • Layered pawn structure after Lyra: a base character for what any pawn needs, a hero character for the player, with ability, combat and input components hanging off the pawn rather than accumulating on one class.
  • Abilities granted from a data asset on possession, so adding one to the hero is a data change rather than a code change.
  • Input bound by gameplay tag. A data asset maps tags to input actions and the input component binds by tag, so routing lives in data instead of a switch statement.
  • Component composition. A shared base for every pawn component carrying typed accessors with compile time checks, so subclasses reach their owner without repeating casts.
  • Weapon specific animation swapped in as a linked layer rather than branching inside one large graph.
