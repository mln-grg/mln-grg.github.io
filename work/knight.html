Combat GAS Project In progress

A combat framework on Unreal's Gameplay Ability System. I am building it to get properly comfortable with GAS, so the list below is honest about how far it has actually got.

Type
Personal project
Engine
Unreal Engine 5, C++
Status
In progress, started Aug 2026
Source
github.com/mln-grg/Knight
  • GAS is the part of Unreal I most wanted to know cold, so I am building a combat framework on it instead of reading about it.
  • Structure follows Lyra, scaled down: a base character with what any pawn needs, a hero character on top, and ability, combat and input as components on the pawn rather than one swollen class.
  • Abilities come from a data asset and are granted when the pawn is possessed, so giving the hero a new ability is an asset change, not a code change.
  • Input binds by gameplay tag rather than a switch statement, so routing lives in data.
  • Weapon animation is a linked anim layer, so a new weapon does not mean another branch in one enormous graph.
  • In so far: ability system component and attribute scaffolding, data driven granting, tag input, the character and combat component split, linked anim layers, axe equip and unequip.
  • Not in yet: attributes are declared but not populated, so no health, damage or ability cost. No enemies, no damage resolution, one weapon and no UI.
