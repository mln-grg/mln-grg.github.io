Koi

A puzzle game made for the BYOG 2021 jam on the theme Reset. Sole programmer and designer.

Engine
Unity
Event
BYOG 2021, theme Reset
My role
Sole programmer and designer
Play it
sh4nks0.itch.io/koi
  • One rule carries the game. Chicks follow the hen only while inside her radius. Fall too far behind for too long and a chick resets to where the level started it, which is both the failure state and the clock.
  • The only interesting verb costs you. You can lock a chick in place or send it to a point, which is the only way to split the flock across a gap, and it resets that chick once it lands.
  • The point of the exercise was to make Reset the load bearing rule rather than a word decorating a restart button.
  • Built over a jam weekend: follow behaviour, radius test, reset timer, command state and level flow, all written once.
  • Credits: I was sole programmer and designer, Arjun M Suresh did level design, Liyons Varghese, Sundev Nallees and Nandhu S playtested.
