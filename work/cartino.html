Cartino

A 3D bullet hell where you drive, built in Unity for Android in late 2020. The first thing I made where the structure was a decision.

Engine
Unity
Platform
Android
Built
Oct to Dec 2020
Source
github.com/mln-grg/Cartino
  • A learning project, built to practise clean code and design patterns on purpose rather than by accident.
  • Bullet hell rules on a driveable vehicle. The Android target set the budget for how many projectiles could be alive and how much the enemies could think per frame.
  • Object pooling for projectiles, because allocating a few hundred bullets a second on a phone is the difference between a game and a slideshow.
  • A finite state machine for enemy behaviour, so a new enemy type meant new states rather than new branches.
  • Observer for the events several systems care about, so UI and audio could react without holding references into gameplay.
  • Singletons for the managers. I would use fewer now: they make a dependency graph invisible rather than absent.
