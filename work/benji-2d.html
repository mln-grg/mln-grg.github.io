Benji-2D — engine from scratch

A 2D engine built from nothing but C++ and SDL2, to understand the parts of an engine that are invisible when you use someone else's. Years later it turned out to be the most directly useful thing I had built: the ECS I wrote by hand here is the same idea I now run at four thousand agents in Unreal.

What it is

  • A signature-based ECS with packed component pools. Each entity is an id and a bitmask signature; components live in dense arrays rather than being owned by the entity. Systems declare the signature they care about and iterate contiguous memory.
  • A frame-rate-independent game loop. Simulation stepping decoupled from render rate, so behaviour does not change with the machine it runs on.
  • A type-indexed event bus. Subscription and dispatch keyed on event type, so systems communicate without knowing about each other.
  • AABB collision handling and a Dear ImGui debug layer for inspecting live state.

Why it still matters to me

Writing an ECS from scratch is the difference between knowing that data-oriented design is faster and knowing why. When I later architected soldier simulation on Unreal's Mass Entity framework, none of it was unfamiliar: archetypes, signatures, dense storage, systems over entities. I had already made the mistakes at small scale — the ones about entity lifetime, about where component data really lives, about how much of the win is memory layout and how little is cleverness.

It is also, honestly, the code I hand to people who want to read my C++. My strongest professional work is under NDA. This is not, and it is small enough to read in an evening.
